# Source synchronization

Repository: https://github.com/Oubit1/paper-writing-rsi

This directory is a clean publication checkout. Original author manuscripts, private paper copies, account credentials, SQLite databases, histories, logs and personal writing exemplars are excluded. Do not use `git add` on the original live workspace to publish it.

Publish source changes from this clean checkout after reviewing the staged diff. Large runtime files and the complete share ZIP remain local and must not be uploaded to this repository. Preserve the empty library, disable Crossref discovery by default for new users, and remove local model-validation claims when refreshing configs.

The installer downloads runtime components from the original upstream sources; no complete share package is published on GitHub.

Local maintainer paths: the publication checkout is `D:/paper_agent/github-sync`; packaging scripts, staging directory and shareable artifacts are in `D:/paper_agent/distribution`.
