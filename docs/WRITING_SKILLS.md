# MLNLP Paper Writing Tips

上游：https://github.com/MLNLP-World/Paper-Writing-Tips/tree/50712564062249b28b8493ebdc35f8b3a3b88512/paper-writing

`paper-writing` 已接入章节写作、教师讨论、PDF 局部修订、独立审阅、校准及兼容编辑器。写作角色读取核心规则；审阅操作和审稿/校准角色额外读取终稿清单。翻译和经验维护不加载此 Skill。详细示例与学习资源供独立调用时按需读取，不挤占每次模型请求。

工作台将社区建议视为条件性参考，优先遵循当前作者要求、已确认的期刊模板、数学含义及原文范围。保留待作者接受的局部建议机制；不会自动改原稿、投稿或上传到第三方语法服务。PDF、匿名性、篇幅等缺少核验材料时必须标明未核实。

安装：`python scripts/install_paper_writing_skill.py`。该脚本固定上游提交、核验四个 Markdown 文件的 SHA256，加入本地适配说明；不执行上游代码，也不会静默覆盖用户自行改过的 Skill。更换上游版本需先复核内容并更新 `configs/paper_writing_upstream.json`，没有自动更新任务。

源码编辑任务会保存实际注入的 Skill 文件哈希、字符范围和提供器交付状态。规则内容变化后，同一请求不复用旧规则生成的缓存。记录只证明内容进入提示词，不证明模型理解或每条建议正确。社区规则占独立的 12,000 字符上限，不挤占作者已绑定指南的预算。

本机 Skill 在 `skills/paper-writing`，Codex 的同名全局 Skill 指向该目录。上游固定版本未发现 LICENSE；GitHub 源码仅包含适配代码、来源清单和下载脚本，安装时直接从上游获取原文。没有重新发布上游全文或示例图片；上游规则中的图片名只作出处提示。

验证包含隔离环境的角色路由、提示词注入、缓存失效、原稿不被自动替换和完整控制面回归；不将合成提供器测试表述为真实模型写作质量评估。
